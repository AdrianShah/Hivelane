<h2 class="hl-section-title">
  Two minutes to set up.<br />
  <span class="tone">Nothing to learn after that.</span>
</h2>

<ol class="hl-steps not-content">
  <li>
    <strong>Install the CLI</strong>
    <p>Once per machine. See <a href="{{BASE}}/install/">Install</a> for every option.</p>
  </li>
  <li>
    <strong>Run <code>hivelane up</code> in your repo</strong>
    <p>Installs the agent hooks, creates a room and starts a small background daemon.</p>
  </li>
  <li>
    <strong>Share the room with your team</strong>
    <p>Each teammate runs the same command. Their agents now check with each other before every edit.</p>
  </li>
</ol>

<h2 class="hl-section-title">
  Built for how teams<br />
  <span class="tone">actually use agents.</span>
</h2>

<CardGrid>
  <Card title="Checks before every write" icon="approve-check">
    Agent hooks ask before each edit. The answer is allow, warn or block, down
    to the function or line range a teammate is in.
  </Card>
  <Card title="Every agent in one room" icon="puzzle">
    Claude Code, Codex, Cursor and Gemini CLI through native hooks, anything
    else through `hivelane run`, and people through the VS Code extension.
  </Card>
  <Card title="A live dashboard" icon="laptop">
    One lane per agent with its intent, plan and latest diffs, and every warn
    or block with the reason behind it.
  </Card>
  <Card title="Yours to host" icon="seti:docker">
    The relay is one small process in a container. Run it on your own
    infrastructure and nothing leaves your network.
  </Card>
</CardGrid>
