<h2 class="hl-section-title">Quick start</h2>

<ol class="hl-steps not-content">
  <li>
    <strong>Install the CLI</strong>
    <p>Once per machine, with pipx or uv. See <a href="{{BASE}}/install/">Install</a> for every option.</p>
  </li>
  <li>
    <strong>Run <code>hivelane up</code> in your repo</strong>
    <p>Installs the agent hooks, creates a room and starts a small background daemon.</p>
  </li>
  <li>
    <strong>Commit <code>.hivelane.toml</code></strong>
    <p>It records the room and relay, so teammates join automatically.</p>
  </li>
  <li>
    <strong>Teammates run the same command</strong>
    <p>Their agents now check with each other before every edit.</p>
  </li>
  <li>
    <strong>Open the dashboard</strong>
    <p>Watch every lane live at <a href="{{SITE_HOME}}start">the dashboard</a>.</p>
  </li>
</ol>
